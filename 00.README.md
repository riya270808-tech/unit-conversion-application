# Unit Conversion Application
Project Overview

The Unit Conversion Application is a simple console-based Python project that performs conversions between different units.

The application allows the user to select a conversion option, enter a numerical value, and receive the converted result. The program also validates user input and displays an error message when invalid input is entered.

The project is designed as a beginner-level Python application and focuses on basic programming concepts such as functions, conditional statements, loops, input handling, validation, and mathematical calculations.

## Features

* Console-based application
* Simple menu-driven system
* Meter to Kilometer conversion
* Kilometer to Meter conversion
* Meter to Feet conversion
* Feet to Meter conversion
* Input validation
* Error messages for invalid input
* Option to perform another conversion
* Option to exit the application

## How to Install and Run

### Step 1: Install Python

Install Python on your computer if it is not already installed.

### Step 2: Download or Clone the Repository

Download the project from GitHub or clone the repository using Git.

### Step 3: Open the Project Folder

Open the project folder in Visual Studio Code or another Python editor.

### Step 4: Run the Program

Open the terminal inside the project folder and run:

```bash
python main.py
```

The application will start in the terminal.

## How to Use

1. Run the program.
2. View the conversion menu.
3. Select a conversion option.
4. Enter the numerical value.
5. The program performs the calculation.
6. The converted result is displayed.
7. Select whether to perform another conversion or exit.
